# Air Quality Intelligence Pipeline

An environmental data engineering and geospatial analytics system developed for research and development purposes using APIs, ETL pipelines, SQL analytics, GIS visualization, and interactive dashboards for real-time urban air-quality monitoring.

## Project Outcomes
- Collected and processed real-time air-quality data from urban locations
- Transformed raw API responses into structured analytical datasets
- Performed environmental analytics and pollution trend analysis
- Generated GIS-based pollution visualizations and interactive dashboards

## Technologies
Python • REST APIs • Pandas • PostgreSQL • SQL • Streamlit • Folium • GIS • GitHub

## Workflow

```text
API → ETL Pipeline → Environmental Analytics → GIS Visualization → Dashboard
```
