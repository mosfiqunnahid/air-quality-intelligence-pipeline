# Air Quality Intelligence Pipeline

An environmental data engineering and geospatial analytics system developed for research and development purposes using APIs, ETL pipelines, SQL analytics, GIS-based spatial visualization, interactive dashboards, and environmental data analysis for real-time urban air-quality monitoring.

## Project Outcomes
- Collected and processed real-time air-quality data from multiple urban locations
- Transformed raw API responses into structured analytical datasets
- Performed environmental analytics and pollution trend assessment
- Generated statistical graphs and pollutant distribution visualizations
- Applied GIS and geospatial analytics using latitude and longitude coordinates to create pollution maps, spatial visualization, and environmental hotspot analysis
- Developed an interactive Streamlit dashboard for air-quality monitoring and pollutant analytics

## Technologies
Python • REST APIs • Pandas • PostgreSQL • SQL • Streamlit • Folium • GIS • Geospatial Analytics • Matplotlib • GitHub

## Workflow

```text
API → ETL Pipeline → Environmental Analytics & Graphs → GIS & Geospatial Visualization → Dashboard
```

## Run

```bash
python3 src/main.py
python3 src/eda.py
python3 src/create_map.py

```
